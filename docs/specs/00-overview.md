# 00 — Обзор проекта

Точка входа для агента. Перед реализацией прочитай все спеки в порядке номеров.

## Цель

Веб-приложение для мотивации подготовки к ЕГЭ: пользователь отмечает решённые задания категорий A/B/C, получает очки, растёт по нелинейной RPG-шкале уровней и статусов (от **Ботика** до **Гигачада**), держит серию обязательных занятий и открывает ачивки. Персонаж на экране меняется вместе со статусом (2D-картинки + анимации).

## Пользователи

- Ровно **два фиксированных аккаунта** (логин + пароль).
- Регистрации нет.
- Каждый пользователь видит **только свой** прогресс (приватные данные).
- Аккаунты создаются seed-скриптом при деплое / локальной настройке.

## Границы проекта (в скоупе)

- Ввод занятий: предмет + количество заданий A, B, C.
- Расчёт очков, уровней, статусов по предметам и общего статуса.
- Обязательное расписание: пн — информатика, ср — математика, чт — русский.
- Серия занятий (streak): пропуск обнуляет серию, очки не отнимаются.
- Ачивки.
- 2D-персонаж со статусами (заглушки SVG, затем замена картинками).
- Анимации: idle, начисление очков, level up, смена статуса, toast ачивки.
- Графики прогресса (недели, предметы, A/B/C, календарь занятий).
- Хранение результатов на сервере (Neon Postgres).
- Деплой на Vercel Hobby.

## Вне скоупа (не делать без отдельной спеки)

- Открытая регистрация и больше двух пользователей.
- Соревнование / видимость чужого прогресса.
- Учёт правильности ответов (только «решено»).
- Ввод по номерам заданий ЕГЭ.
- Штраф опыта за пропуск.
- 3D-модели.
- Telegram-напоминания, пробники, обратный отсчёт до ЕГЭ.
- Внешний Auth-провайдер (Clerk и т.п.).

## Стек

| Слой | Выбор |
|------|--------|
| Фреймворк | Next.js (App Router), TypeScript |
| Стили | Tailwind CSS |
| Хостинг | Vercel Hobby |
| БД | Neon Postgres (Vercel Marketplace) |
| ORM | Drizzle |
| Auth | Логин/пароль, хэш пароля в БД (bcrypt или argon2), подписанная httpOnly-сессия |
| Анимации | Motion (`motion` / Framer Motion) |
| Графики | Recharts |
| Конфиг игры | `config/game.ts` — все числа и тексты |
| Логика | Чистые функции в `lib/game/` + юнит-тесты |

## Глоссарий

| Термин | Значение |
|--------|----------|
| **Предмет / дисциплина** | Один из: `informatics`, `math`, `russian` |
| **Трек** | Шкала прогресса: `overall` или конкретный предмет |
| **Задание A / B / C** | Категория сложности; веса 1 / 10 / 50 очков |
| **Запись (entry)** | Факт занятия за день по предмету: counts A, B, C |
| **Очки (XP)** | `A*1 + B*10 + C*50` |
| **Уровень** | Нелинейная шкала; переход с `n` на `n+1` стоит `round(10 * n^1.5)` XP |
| **Статус** | Именованный ранг (Ботик … Гигачад) с картинкой; открывается с порогового уровня |
| **Обязательное занятие** | Пн/ср/чт по расписанию предмета дня |
| **Серия (streak)** | Число подряд выполненных обязательных занятий |
| **Ачивка** | Одноразовое достижение, хранится в `user_achievements` |

## Структура репозитория (целевая)

```
config/game.ts          # веса, уровни, статусы, расписание, ачивки, timezone
lib/game/               # расчёт XP, уровней, статусов, streak, ачивок
lib/auth/               # сессия, хэш пароля
lib/db/                 # Drizzle schema, client
app/                    # Next.js App Router (страницы + server actions)
public/characters/      # SVG-заглушки персонажей
docs/specs/             # эти спеки
scripts/seed.ts         # создание двух пользователей
```

## Порядок реализации для агента

1. **Каркас + механика** — Next.js, Tailwind, `config/game.ts`, `lib/game/` с тестами. Спеки: `01`.
2. **БД + auth + seed** — Neon, Drizzle, вход, два аккаунта. Спека: `02`.
3. **Ввод занятия + главная** — формы, дашборд, страницы предметов. Спеки: `02`, `03`.
4. **Анимации + ачивки** — Motion, тосты, эволюция статуса. Спеки: `01`, `03`.
5. **Графики** — Recharts, календарь. Спека: `03`.
6. **Деплой** — Vercel + Neon + env + seed. Спека: `04`.

На каждом этапе закрывай критерии приёмки соответствующей спеки.
