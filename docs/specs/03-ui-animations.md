# 03 — UI, персонаж, анимации, графики

## Общие требования UI

- Язык интерфейса: **русский**.
- Адаптив: удобно с телефона (основной сценарий — быстрый ввод после занятия).
- Тёмная/светлая тема: v1 достаточно одной (предпочтительно тёмная «игроподобная»).
- Навигация: главная, ввод, предметы (или карточки с переходом), ачивки, графики, выход.

## Экраны

### `/login`

- Поля: логин, пароль, кнопка «Войти».
- Ошибка при неверных данных без утечки «логин существует / нет».

### `/` — главная (дашборд)

- Персонаж **общего** статуса (`overall`) + название статуса + уровень + полоса XP до следующего уровня.
- Текущая **серия** (streak) крупно.
- Блок «Сегодня»: если день обязательный — предмет дня и статус «выполнено / ещё нет» (порог `minSessionXp`).
- Три карточки предметов: статус (мини-картинка), уровень, полоса XP, сумма XP.
- Кнопка/ссылка «Записать занятие».

### `/log` — ввод занятия

- Выбор предмета (по умолчанию — предмет дня, если день обязательный; иначе последний выбранный или информатика).
- Три счётчика A / B / C (stepper или number input, ≥ 0).
- Живой предпросмотр XP: `A*1 + B*10 + C*50`.
- Если за сегодня по предмету уже есть запись — показать текущие значения и режим «обновить».
- После сохранения — редирект на главную или оверлей наград (см. анимации), затем главная.

### `/subjects/[subject]`

- Персонаж предмета, статус, уровень, полоса.
- Лестница всех статусов: пройденные / текущий / закрытые.
- История записей (дата, A/B/C, XP), новые сверху.
- Удаление/правка только если дата = сегодня.

### `/achievements`

- Сетка: полученные (цветные, дата) и закрытые (заглушка / силуэт, условие текстом без спойлеров прогресса — можно показывать условие).

### `/charts`

См. раздел «Графики».

## Персонаж (2D)

Путь ассетов:

```
public/characters/{track}/{statusId}.svg
```

- `track`: `overall` | `informatics` | `math` | `russian`
- `statusId`: `botik` | `nubik` | `normis` | `sharyashiy` | `tasher` | `sigma` | `gigachad`

Итого **28** файлов-заглушек. Заглушка: простой SVG с текстом названия статуса и цветом трека. Позже файлы заменяются без смены кода (те же имена).

Компонент `CharacterPortrait`:

- props: `track`, `statusId`, `size`, `animateIdle?: boolean`
- alt/текст: название статуса.

## Анимации (Motion)

| Сценарий | Поведение |
|----------|-----------|
| Idle | Лёгкое покачивание / дыхание портрета (loop, низкая амплитуда) |
| XP gain | Число «+N XP», полоса плавно заполняется от `before` к `after` |
| Level up | Вспышка / scale-bounce, обновление номера уровня; может сработать несколько раз подряд, если прыжок большой |
| Status change («эволюция») | Старая картинка → dissolve/swap → новая; короткое конфетти |
| Achievement toast | Всплывающая карточка снизу/сверху с названием; очередь, если несколько |

Триггер: ответ `upsertEntry` с `before` / `after` / `newlyUnlocked`. Клиент сравнивает уровни и statusId по трекам.

Анимации не блокируют сохранение данных; при `prefers-reduced-motion` — мгновенная смена без эффектов.

## Графики (Recharts)

Данные с `getCharts`:

1. **XP по неделям** — столбцы или линия: суммарный XP за календарную неделю (пн–вс в timezone приложения), опционально stacked по предметам.
2. **Разбивка по предметам** — pie или bar: доля / сумма XP `informatics` / `math` / `russian`.
3. **Разбивка A / B / C** — bar: вклад в XP (не сырые counts, либо оба режима; v1 — вклад в XP).
4. **Календарь занятий** — сетка дней: обязательные слоты отмечены выполнен / пропущен / ещё не наступил; необязательные дни с записью — отдельный маркер «доп.».

Пустое состояние: понятный текст «Пока нет данных — запиши первое занятие».

## Критерии приёмки

- [ ] Все экраны из списка реализованы и доступны после логина.
- [ ] 28 SVG-заглушек на месте; портрет меняется при смене статуса.
- [ ] После сохранения видны анимации XP / level up / эволюция / toast при соответствующих событиях.
- [ ] `prefers-reduced-motion` отключает декоративные анимации.
- [ ] На `/charts` четыре вида визуализаций с данными текущего пользователя.
- [ ] Мобильная вёрстка: ввод A/B/C удобен одним пальцем.
